# Indhra Projects website

Open `index.html` in VS Code.

- `index.html`: the page content and structure
- `css/style.css`: all the styling (colours, layout, animations)
- `js/main.js`: the behaviour (pages, forms, tickers, the WhatsApp hand-off)
- `assets/`: the background image and the logo

To see changes live, install the "Live Server" extension in VS Code, then right-click `index.html` and choose "Open with Live Server".

Set your WhatsApp number near the top of `js/main.js` (the `WHATSAPP_NUMBER` line). To email each enquiry or registration to you, paste a form endpoint into `NOTIFY_URL` in the same file.
